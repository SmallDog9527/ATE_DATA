# Custom Agent Rules

-
- **任务执行流程 (Workflow)**: 每次任务必须按以下流程执行：
  1. **先查原因**: 深入排查问题根源，在此期间绝对不要修改任何代码。
  2. **提出修改计划**: 查完原因后，向用户汇报具体原因以及计划如何修改，并提供清晰的修改方案。
  3. **等待用户授权**: 仅在用户确认同意修改计划后，才可以着手修改代码。
- **自动登录SSH并切换目录**: 当用户说“登陆ssh myserver”后，会自动登录并切换到 `/home/ATE_DATA` 目录，然后询问用户要执行什么操作。
- **英文备注规则**: 除前端项目外，所有后端代码注释、系统日志描述以及写入数据库的各种状态/错误备注（如 FTP 上传/解析失败等记录）必须全部使用英文表达，禁止出现中文。
 - **任务结束回复**: 每次任务结束后，必须在回复的结尾加上：`喵~已完成~~`
- **Gitee 提交规则**: 除非用户明确要求提交或推送，否则在完成代码修改后，只需在服务器本地保存并使之生效即可，绝对不要主动执行 `git commit` 或 `git push` 到 Gitee 远端。
